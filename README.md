# GUESS THE NUMBER GAME

# DESCRIPTION: 
This is a simple console-based "Guess the Number" game written in Python. The computer randomly selects a number between 1 and 100, and the player's goal is to guess that number. The game provides hints (too high or too low) after each guess until the correct number is found. A simple 'Guess the Number' game.
The computer picks a random number, and the user tries to guess it.

# FEATURES
- Random number generation.
- User input for guesses.
- Feedback on guesses (too high/too low).
- Tracks the number of attempts.
- Error handling for invalid input.

# HOW TO PLAY
1. Run the Python script guess_the_number.py.
2. The game will prompt you to enter your guess.
3. Type a whole number and press Enter.
4. The game will tell you if your guess was too high, too low, or correct.
5. Keep guessing until you find the secret number!
